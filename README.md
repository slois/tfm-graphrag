    # Framework GraphRAG para la interpretación explicable de variantes genómicas como apoyo a la decisión clı́nica

Desde la implementación de la secuenciación de nueva generación (NGS) en la rutina clı́nica, la interpretación de variantes genómicas constituye un cuello de botella persistente debido al volumen de datos y la complejidad de la evidencia cientı́fica necesaria para establecer causalidad. Si bien la Inteligencia Artificial promete agilizar este proceso, la naturaleza de ”caja negra” de los modelos actuales limita su adopción en entornos donde la transparencia es un requisito ético y legal. Este trabajo propone un framework basado en la arquitectura GraphRAG para la interpretación explicable de variantes. Partiendo de la base de conocimiento MonarchKG, se aplica una metodologı́a de Smart Pruning para construir un subgrafo especializado en una prueba piloto que incluye genes asociados a rasgos dismórficos, discapacidad intelectual y epilepsia sindrómica de aparición temprana. Este subgrafo se enriquece con literatura de PubMed Central y otras bases de datos biomédicas. El sistema ancla la capacidad de los Grandes Modelos de Lenguaje (LLMs) a esta estructura de alta fidelidad, permitiendo generar rutas de evidencia auditables que cumplen con los estándares de transparencia del Reglamento de IA de la UE y proporcionan un soporte a la decisión clı́nica bajo un enfoque de ”caja de cristal”.
